# Assets — what to drop in this folder

Every file below is referenced from the `SITE` object in `index.html`. The page
is built to survive missing files:

- a missing **paper thumbnail** draws a neutral chart graphic
- a missing **institution logo** draws a lettered monogram (`JN`, `SI`, …)
- a missing **carousel photo** draws a neutral image placeholder
- a missing **profile photo** draws a monogram

Nothing ever renders as a broken-image icon, so add these in whatever order
suits you. File names must match exactly (lowercase, hyphens, no spaces) — or
change the path in `SITE` to match what you upload.

## 1. Profile photo — DONE, generated

| File | Dimensions | Format | Notes |
|---|---|---|---|
| `profile.jpg` | 1000 × 999 (square) | JPG, 160 KB | Sits at the right of the hero, up to 23 rem wide. |

**Do not edit this file by hand.** It is built by `python tools/build_media.py`
from whatever single image sits in `profile photo/` — the file name does not
matter, so replacing the portrait means dropping the new original in that folder
and re-running the tool. The default crop keeps the full width and trims the
bottom fifth, which lands just below the pockets and comes out square.

The crop is four numbers — `PROFILE_CROP` at the top of `tools/build_media.py`,
given as fractions of the original (left, top, right, bottom). The tool prints
the resulting size and aspect ratio so you can tune them. The CSS then fits that
file with `object-fit: cover`, so a longer or shorter bio only trims background,
never the face.

Referenced by: `SITE.profile.photo`

## 2. Open Graph preview image — required for link sharing

| File | Dimensions | Format | Notes |
|---|---|---|---|
| `og-image.png` | **1200 × 630** (exact) | PNG or JPG, < 300 KB | Shown when the URL is pasted into Slack, X, LinkedIn, WhatsApp, iMessage. |

Keep it simple: your name in large type, one line of research identity, the
university name, optionally a small figure from a paper. Leave ~60 px of padding
on all sides — some platforms crop the edges.

Referenced by: `SITE.meta.ogImage` **and** the static `og:image` / `twitter:image`
tags in `<head>`. Link-preview scrapers do not run JavaScript, so if you rename
this file you must update both places.

## 3. Paper thumbnails — 9 files, one per publication

| File | Dimensions | Format | Notes |
|---|---|---|---|
| `pub-j1.png` … `pub-j4.png` | **800 × 800** (square) | PNG, < 200 KB each | Journal papers |
| `pub-c1.png` … `pub-c4.png` | **800 × 800** (square) | PNG, < 200 KB each | Conference papers |
| `pub-d1.png` | **800 × 800** (square) | PNG, < 200 KB | Dataset |

**Square, not wide.** The thumbnail renders at 88 × 88 px on desktop with
`object-fit: cover`, so a wide architecture diagram gets centre-cropped and you
lose both ends of it. Crop to a square yourself and you control what survives.
(On phones the same image stretches to a full-width 2:1 band, which is forgiving.)

Clicking a thumbnail opens the **full image in a modal**, so the file can carry
real detail — it is not only a 88 px chip. 800 × 800 is a good compromise.

What works at thumbnail size: one tight crop of an architecture diagram, a
single results plot with legible axes, a qualitative example (sky image with the
prediction overlaid). What does not: a full multi-panel figure, a screenshot of a
table, the paper's first page.

Leave `thumb: ""` in `SITE.publications` for any paper you have not made a
thumbnail for — the placeholder is deliberately neutral and the card still looks
finished. Set `thumb: "assets/pub-j1.png"` when ready.

**Also fill in `thumbAlt`** for each. Describe what the figure shows ("Model
architecture: sky-image encoder and weather branch fused before a temporal
decoder"), not what it is ("Figure 1"). It is read aloud by screen readers and
used as the modal's caption fallback.

Referenced by: `SITE.publications[].thumb` / `.thumbAlt`

## 4. Carousel photos — not in this folder

The photographs live in `Photos/`, not here. One folder per event, each with a
`caption.txt`; `python tools/build_media.py` writes the web copies into
`Photos/web/` and prints the array. See "Adding photos and videos" in the root
README.

The carousel sits beside the News list, auto-advances every 4.5 seconds (9 for a
video clip), pauses on hover and on keyboard focus, restarts after an arrow
click, and does not move at all for a visitor who has asked for reduced motion.
Past ten slides the dot row becomes a plain "4 / 33" counter.

Referenced by: `SITE.galleryPhotos[]`

## 5. Institution logos

| File | Dimensions | Format | Notes |
|---|---|---|---|
| `logo-jnu.png` | **128 × 128** | PNG with transparency, or SVG | Jeju National University |
| `logo-sukkur-iba.png` | **128 × 128** | PNG with transparency, or SVG | Sukkur IBA University |
| `logo-augmented-startups.png` | **128 × 128** | PNG with transparency, or SVG | Augmented Startups |
| `logo-masterminds.png` | **128 × 128** | PNG with transparency, or SVG | Masterminds Enterprise |

Square canvas, logo centred with a little breathing room, transparent
background. Displayed at 30 × 30 px, so a logo with fine text will turn to mush —
prefer the crest/mark over the full lockup where there is a choice.

A near-black logo on transparent disappears in dark mode. If that is the case,
use the light variant or one with its own background. Omit a file and a lettered
monogram is drawn instead, which looks intentional. Only use logos you are
entitled to use.

Referenced by: `SITE.experience[].logo`, `SITE.education[].logo`
